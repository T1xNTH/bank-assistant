# Tài liệu API

## Mục đích

Mục lục cho contract, interface, endpoint, schema và định nghĩa event chính thức.

## Nội dung

- `contract.md` - Contract và trạng thái nạp/kiểm tra
- `openapi.yaml` - Đặc tả OpenAPI (nguồn chuẩn dạng máy đọc)
- `rest-api.md` - Contract REST, khi được cung cấp
- `graphql.md` - Contract GraphQL, khi được cung cấp
- `event-contracts.md` - Contract event, khi được cung cấp

Hiện chỉ có `contract.md`; input contract chính thức vẫn đang bị chặn bởi `BLOCKER-002`.
