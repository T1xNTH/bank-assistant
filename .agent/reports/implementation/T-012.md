## Scope

Implement chat(messages, alias, temperature) returning the existing LLMResult contract.
The runtime fake needs no credentials or network. Real calls use LLM_BASE_URL and
LITELLM_MASTER_KEY; provider credentials are never read by the client.

## Changes Made

- Select fake/litellm from the current LLM_BACKEND environment on each call.
- Use the repository's httpx2 client as a runtime dependency, with a 30 second
  timeout, disabled redirects, and no inherited proxy environment.
- Retry only HTTP 429 and 5xx, at most three attempts, waiting 0.5 then 1 second.
  Keep messages, alias and temperature unchanged across attempts.
- Set reasoning_effort=none for cloud-chat, matching the existing smoke tool;
  the pinned gateway rejects the configured reasoning model's temperature without it.
- Return content, provider model and usage token counts; absent usage defaults to zero.
- Reject malformed responses and expose only generic transport/response errors or
  HTTP status codes, never gateway error bodies, prompts or secrets.
- Test against a local HTTP server and the pinned real LiteLLM with fake OpenAI.
