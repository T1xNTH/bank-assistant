## Proposed Change

Add the existing Unavailable (503) response to POST /chat in the authoritative
OpenAPI contract and generated API schema. Trim surrounding whitespace from chat
messages and generated answers, reject blank messages before invoking the LLM,
and reject blank answers with the existing safe 503 envelope.

## Justification

PR55-F01 found a runtime status missing from the documented contract. PR55-F02
reproduced chargeable calls for whitespace-only input and successful blank replies.
